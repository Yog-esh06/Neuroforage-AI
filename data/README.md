# data/

| Folder | Content |
|---|---|
| `sample/` | Demo and evaluation corpus. Generated by `backend/scripts/generate_sample_data.py` (real PDFs, an image-only scanned PDF, XLSX, DOCX, TXT). Safe to delete and regenerate with `make sample`. |
| `eval/` | `eval_dataset.json` — classification labels, retrieval questions with expected evidence (document + key phrases), answer cases (including must-refuse questions) and expected contradictions. Labels were written from the *source* of the generated documents, not from system output. |
| `processed/` | Evaluation reports (`eval_report.json`). Git-ignored. |

The sample corpus is deliberately adversarial:

* `master_services_agreement_acme_globex.pdf` and `amendment_1_acme_globex.pdf` disagree on expiry date, contract value,
  notice period, payment terms, late-payment rate, governing law → contradiction detection and comparison.
* `invoice_inv2042_total_error.pdf` states a total that is not the sum of its rows → table reconciliation finding.
* `scanned_invoice_inv3307.pdf` has no text layer (rotated, noisy, ruled table) → OCR + grid-table recovery.
* `annual_report_fy2025.pdf` contains risk language and a **negated** going-concern sentence → negation handling.
* The remaining files exercise classification (paper, policy, resume, spreadsheet).

Uploaded documents at runtime live in `storage/documents/` (or S3), not here.
